# 层级 1：自有域名 + 国内托管 + 备案

这条路是唯一不受「名单轮换」影响的方案：域名是你自己的、服务器在境内、连通性与速度由国内网络保证。
代价是备案周期。下面是可执行的顺序，以及每一步要准备什么、容易踩什么坑。

---

## 0. 先决定三件事（顺序不能颠倒）

1. **域名在境内注册商买**：阿里云、腾讯云、华为云都可以。**境外注册的域名（Namecheap / GoDaddy / Cloudflare Registrar）无法备案**，只能等 60 天后转入境内，所以直接从境内买最省事。约 50–80 元/年。
2. **同一家买一台最小规格的轻量应用服务器**：备案要求你在**境内有一台有效期 ≥3 个月的云服务器**（备案服务码从它生成）。最便宜的轻量档通常有年付促销（常见 99 元/年档）。
   备案绑定的是你的账号与这台服务器，服务器不一定要当主机用，但**备案期间和通过后都要保持有效**，否则备案可能被注销。
3. **网站名称先想好**：个人备案对名称有硬要求——
   - 不能含企业/机构名称、不能含「中国 / 中华 / 中央」等字样
   - 不能是纯行业词或纯地名（例如「国学」「背诵」单独作为名称容易被退）
   - 建议写成一个具体的长名，例如「某某的国学背诵笔记」「某某诵读练习册」
   - 名称会出现在备案信息里，后续不要频繁改

---

## 1. 域名实名认证（1 个工作日左右）

买完域名先做实名认证，**实名信息必须与备案主体（你本人）完全一致**：姓名、证件号一致。域名未实名或实名不一致，备案会直接卡住。

---

## 2. 提交备案（管局审核 1–20 个工作日，多数 5–10 天）

在你买服务器的那家云厂商的 App / 控制台里走「备案」流程，全程手机人脸核验：

- **主体信息**：身份证、手机号、常用邮箱、真实住址
- **网站信息**：域名、网站名称（见第 0 步）、服务内容（个人一般选「其他」或「学习」）
- **服务器信息**：选那台轻量服务器，生成/填入备案服务码
- 云厂商初审 1–2 天 → 提交管局 → **管局可能会打电话核验**，问「网站名称是什么、做什么用的、域名是不是你的」——接电话、照备案信息回答即可，别漏接

⚠️ 备案期间：**域名不要解析到境内服务器上对外访问**。云厂商会要求关闭访问，否则可能驳回。
先用 **服务器 IP** 直连测试（例如 `http://你的服务器IP`），这不影响备案。

---

## 3. 服务器上装好站点（备案期间就能做）

在轻量服务器上（Ubuntu/Debian 示例）：

```bash
sudo apt update && sudo apt install -y nginx
sudo mkdir -p /var/www/guoxue
# 把 deploy/国学背诵-dist.zip 里的内容解压进 /var/www/guoxue（用 scp / 宝塔面板都行）
sudo chown -R www-data:www-data /var/www/guoxue
```

把仓库里的 `deploy/nginx.conf` 复制到 `/etc/nginx/conf.d/guoxue.conf`，把 `server_name` 换成你的域名，然后：

```bash
sudo nginx -t && sudo systemctl reload nginx
```

**这个 App 有三条不能省**（配置里已经写好）：
- `try_files $uri $uri/ /index.html` —— 否则刷新 `/review` 会 404（单页应用的回落）
- `sw.js` 必须 `no-cache` —— 否则更新永远发不出去
- `.webmanifest` 必须是 `application/manifest+json` —— 否则 iPhone 认不出这个 PWA

此时用 IP 访问应该能看到 App 的空状态（「还没有可背的篇目」）。

---

## 4. 备案通过后：解析域名

在域名商控制台加一条 A 记录：

| 类型 | 主机记录 | 记录值 | TTL |
| --- | --- | --- | --- |
| A | `@` | 你的服务器公网 IP | 600 |
| A | `www` | 你的服务器公网 IP | 600 |

生效通常几分钟到十几分钟。验证方式（在有代理或已能解析的机器上）：

```bash
nslookup 你的域名 8.8.8.8
curl -I http://你的域名
```

---

## 5. 配 HTTPS（PWA 必须 HTTPS 才能装到主屏）

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名 -d www.你的域名
```

certbot 会自动改写 Nginx 配置加上 443 段与 80→443 跳转，并设置自动续期。

---

## 6. 收尾三件小事

1. **公安联网备案**：备案通过后 30 天内，在「全国互联网安全管理服务平台」提交公安备案（填主体、网站信息即可，部分地区要求现场核验）。云厂商控制台通常也会提醒。
2. **备案号放页脚**：网站底部写明备案号并链接到 `https://beian.miit.gov.cn/`（合规要求）。这一步我可以直接加到 App 的页脚里。
3. **用同一个脚本复验**：仓库里有 `scripts/dev/verify-deploy.mjs`，把域名传给它，它会逐项检查首页、`/review` 回落、清单、`sw.js` 缓存头、图标与构建产物是否与本地一致：

```bash
node scripts/dev/verify-deploy.mjs https://你的域名 none
```

（第三个参数传 `none` 表示不使用代理直连。）

## 成本与时间一览

| 项目 | 费用 | 时间 |
| --- | --- | --- |
| 域名 | 约 50–80 元/年 | 即时 |
| 轻量服务器（最便宜档） | 常见 99 元/年促销，或 ~24 元/月 | 即时 |
| 备案 | 免费 | 1–20 个工作日（多数 5–10 天） |
| HTTPS 证书 | 免费（Let's Encrypt / 云厂商） | 5 分钟 |
| 公安备案 | 免费 | 30 天内完成 |

一个月内能全部落地。这期间 Vercel 那份继续能用（挂代理访问），不冲突。
